How the corpus was built

GitHub's web code search returns at most 100 results per query, so the harvester splits a query that hits the cap into narrower ones by language, archived state, file extension, directive option, and software term, until each returns fewer than 100. Search results only identify repositories. Each repository is then shallow-cloned and every file under 384 KB is checked for directive lines, so one hit can yield many scripts.

Get the data

Files

  • scripts/scripts-XX.jsonl.gz: one JSON record per unique script, in 256 files keyed by the first two hex digits of the script's git blob SHA.
  • index.csv.gz: one row per script and manager with flat metadata and labels, no content. Start here for analysis.
  • repos.csv.gz: one row per repository with license, stars, and scan status.
  • manifest.json: counts, field descriptions, and a SHA-256 for every file.

One script record

  • blob_sha, size, managers, directive_lines
  • content: the script text
  • occurrences: each repository, commit, path, permalink, and license where it was found
  • labels: per manager, every option read and the normalized fields
  • totals: per manager, job-level nodes, tasks, GPUs, walltime, queue, array size

Load it

import gzip, json
import pandas as pd

index = pd.read_csv("index.csv.gz")
gpu_jobs = index[(index.manager == "slurm") & (index.gpu_request == 1)]

def script(blob_sha):                       # full record, with content
    with gzip.open(f"scripts/scripts-{blob_sha[:2]}.jsonl.gz", "rt") as fh:
        return next(r for r in map(json.loads, fh) if r["blob_sha"] == blob_sha)

Search everything locally

With the SQLite database in the repository directory, the explorer serves a search interface over every script: filter by manager, repository, path, queue, nodes, tasks, GPUs, walltime, or any text in the script.

python3 explorer.py        # then open http://127.0.0.1:8000

Before you reuse scripts

Scripts are copied from public repositories and remain under their repositories' terms. Scripts can contain account names, email addresses, and home paths.
